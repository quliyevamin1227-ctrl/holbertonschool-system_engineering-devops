# Web infrastructure design

Whiteboard designs (as text diagrams) and explanations for www.foobar.com:

- `0-simple_web_stack` - one server with a LAMP-style stack
- `1-distributed_web_infrastructure` - load balancer + 2 servers with Primary-Replica MySQL
- `2-secured_and_monitored_web_infrastructure` - firewalls, HTTPS and monitoring
- `3-scale_up` - load balancer cluster and components split on their own servers
